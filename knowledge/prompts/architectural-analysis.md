# Architectural Analysis Prompt

Analyze the repository focusing on:

- dependency structure
- module boundaries
- architectural smells
- cyclic dependencies
- fan-in / fan-out imbalance
- cohesion issues
- excessive coupling

Rules:
- avoid superficial conclusions
- distinguish orchestrators from god objects
- correlate structural and temporal signals
- explain WHY each issue matters

Expected Output:
- severity
- rationale
- evidence
- affected files
- suggested refactors
